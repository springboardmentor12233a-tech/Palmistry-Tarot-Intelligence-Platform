# AI Palmistry & Tarot Intelligence Platform

## Overview

An AI-powered web application that analyzes palm images and tarot card selections to generate personalized insights, complete with user authentication, reading history, an admin dashboard, and downloadable PDF reports.

## Tech Stack

- Frontend: React (Vite), React Router, Axios, Recharts, Lucide React
- Backend: FastAPI
- Database: MongoDB (via Motor async driver)
- Authentication: JWT (python-jose) with bcrypt password hashing, role-based access control (RBAC)
- Machine Learning: PyTorch (UNet), MediaPipe, OpenCV, scikit-image
- LLM Interpretation: Groq API (openai/gpt-oss-120b)
- PDF Reports: fpdf2
