## Planned User Workflow

The final demo workflow will include:

1. Register.
2. Login.
3. View dashboard.
4. Upload palm image.
5. View palm result.
6. Start tarot reading.
7. Draw cards.
8. View interpretation.
9. View personality insights.
10. View recommendations.
11. View life trends.
12. View reading history.
13. Generate and download reports.
14. Use admin dashboard with an ADMIN account.

## Disclaimer

Palmistry and tarot content will be presented as reflective/spiritual content, not guaranteed prediction or professional advice.
